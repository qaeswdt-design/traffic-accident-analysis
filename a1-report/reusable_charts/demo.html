圖表版型示範

下面六張圖都是用 charts.js 畫的,資料是隨機產生的示範資料。每張圖的資料格式見各段程式與 README.md。

1. barList 橫條清單

可點選、可分頁(每頁固定列數)
Charts.barList(host, items, { onClick, pageSize })

2. columns 直條圖(堆疊)

24 小時 × 年齡層堆疊,背景區段標時段
Charts.columns(host, { categories, series, values, bands })

3. forest 信賴區間

點 = 估計值,線 = 95% 信賴區間;空心圓 = 樣本少
Charts.forest(host, items, { base, unit })

4. stackedBars 橫向堆疊條

年齡層 × 車種
Charts.stackedBars(host, rows, series, { legendHost })

5. heatmap 熱度表

格內是件數與該列占比,顏色越深占比越高
Charts.heatmap(host, { rows, cols, matrix })

6. geoScatter 可縮放地圖

滾輪/雙指縮放、拖曳、連點兩下放大;放大後才出現細道路
Charts.geoScatter(host, { outlines, layers, points })
