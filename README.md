# 北北基桃交通事故分析

分析台北市、新北市、基隆市、桃園市的道路交通事故資料,從時間、肇因、道路環境、照明設施、道路設施、當事者特徵到事故結果,找出事故發生的規律。

資料來源:政府資料開放平臺「警政署 道路交通事故」(A1、A2 類),資料集 ID `13139`、`57023`,<https://data.gov.tw>。

## 分析主題

| 章節 | 內容 | 腳本 |
|---|---|---|
| 01A | 事故時間分布(依時段長度標準化為每小時) | `時間上的分析.py` |
| 02 | 主要肇因 TOP 5 | `北北基桃交通事故主要肇因 TOP 5.py` |
| 02B | 各縣市肇因比較(以車輛登記數加權) | `各縣市肇因比較.py` |
| 03 | 道路環境分析(道路型態 × 肇因) | `道路型態肇因分析.py` |
| 04 | 外部環境分析(道路照明設施狀態) | `依光照分析.py` |
| 05 | 道路設施分析(號誌、車道劃分設施) | `road_facility_final.py` |
| 06 | 當事者特徵(年齡、性別、車種 × 縣市) | `關於事故者的交叉分析.py` |
| 07 | 事故結果(死亡率) | `死傷人數分析.py` |
| 延伸 | 事故密度熱點圖、互動式地圖(輸出 HTML) | `事故點分布圖.py`、`互動地圖.py` |

## 專案結構

```
.
├── run_all.py                 # 一鍵產生所有圖表
├── common.py                  # 共用邏輯:資料讀取、篩選第1當事者與四縣市、時段定義、車輛數加權、字型、下載 Session
├── requirements.txt           # 套件與最低版本
├── 當前資料下載更新.py          # 比對官方更新時間,有更新才下載
├── 資料塞入資料庫.py            # 將下載的 CSV/JSON 匯入 SQLite (data.db)
└── 各章節分析腳本 (*.py)        # 每支腳本都 import common,產生對應章節的圖表
```

所有分析腳本都透過 `common.py` 篩選資料,篩選條件只在一個地方維護,修正一次全部生效。

## 資料處理重點

- **只計算第 1 當事者**:同一起事故可能有多位當事者,以「當事者順位等於 1」代表該事故。死亡受傷人數是整起事故的合計,若同一事故取到多列會被重複加總。
- **範圍限定北北基桃四縣市**。
- **肇因合併**:把多種「未依規定讓車」子類別合併為一個大類,並排除「尚未發現肇因」等無效紀錄。
- **車輛數加權**:各縣市規模差異大,事故件數換算為「每十萬輛機動車事故件數」(車輛登記數來自交通部公路局統計)再比較。
- **時段以每小時比較**:早峰 3 小時、日間 7 小時、晚峰 4 小時、夜間 10 小時,長度不同,所以比較的是「每十萬輛車、每小時」的事故件數,而不是整段合計。
- **A1 與 A2 期間對齊**:死亡率的死亡數來自 A1、受傷數來自 A2。A1 是整份 JSON、A2 是逐月 CSV,期間可能不同,所以 A1 會截到 A2 的最後一天再合併計算。
- **年齡範圍**:排除年齡 ≤ 0 與 > 100 的紀錄,未成年當事者(例如騎腳踏車、無照騎機車)保留在分析內。
- **照明設施欄位的意義**:資料欄位「光線名稱」只有「有照明且開啟」「有照明未開啟或故障」「無照明」三種值,記錄的是道路照明設施狀態,涵蓋全部時段(日間事故大多記為「有照明未開啟或故障」,因為白天路燈本來就沒開)。解讀時不能把這一類直接當成路燈故障。

## 使用方式

### 1. 安裝套件

```bash
pip install -r requirements.txt
```

圖表中文字型會依序嘗試 `Microsoft JhengHei`(Windows)、`PingFang TC`(macOS)、`Noto Sans CJK TC`(Linux)等,設定集中在 `common.py` 的 `CJK_FONTS`。

### 2. 準備資料

資料庫檔 `data.db` 與原始下載檔因體積大,**未放進此倉庫**。請自行下載:

```bash
python 當前資料下載更新.py   # 從 data.gov.tw 下載官方資料到 downloads/(有更新時會詢問)
python 資料塞入資料庫.py     # 匯入並產生 data.db
```

下載時會完整驗證 SSL 憑證。內政部下載網址的憑證鏈缺少 Subject Key Identifier,Python 3.13 以上的嚴格模式會拒絕,所以 `common.make_http_session()` 只關閉嚴格模式這一項,憑證鏈、有效期與網域仍會驗證。實在連不上時才使用 `--insecure`(不驗證憑證,不建議)。

`資料塞入資料庫.py` 會自動辨識 `{民國年}_NPA_TMA2_{月}.zip` 的年份與月份,以及 `downloads/` 內最新的 `NPA_TMA1*.json`,跨年不需要改程式。

### 3. 產生圖表

```bash
python run_all.py                       # 以現有 data.db 重跑所有圖表
python run_all.py --refresh             # 先檢查官方資料有無更新(有更新會詢問是否下載),再匯入、重跑
python run_all.py --refresh --yes       # 同上,但有更新就直接下載,不詢問(可全自動)
python run_all.py --with-optional       # 連同熱點圖與互動地圖一起執行
```

所有圖表輸出到 `outputs/` 資料夾。
