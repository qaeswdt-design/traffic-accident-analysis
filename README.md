# 北北基桃交通事故分析

分析台北市、新北市、基隆市、桃園市的道路交通事故資料,從時間、肇因、道路環境、光線、道路設施、當事者特徵到事故結果,找出事故發生的規律。

資料來源:政府資料開放平臺「警政署 道路交通事故」(A1、A2 類),資料集 ID `13139`、`57023`,<https://data.gov.tw>。

## 分析主題

| 章節 | 內容 | 腳本 |
|---|---|---|
| 01A | 事故時間分布 | `時間上的分析.py` |
| 02 | 主要肇因 TOP 5 | `北北基桃交通事故主要肇因 TOP 5.py` |
| 02B | 各縣市肇因比較(以車輛登記數加權) | `橫條圖.py` |
| 03 | 道路環境分析 | `依時間區分.py` |
| 04 | 外部環境分析(光線) | `依光照分析.py` |
| 05 | 道路設施分析(號誌、車道劃分設施) | `road_facility_final.py` |
| 06 | 當事者特徵(年齡、性別、車種 × 縣市) | `關於事故者的交叉分析.py` |
| 07 | 事故結果(死亡率) | `死傷人數分析.py` |
| 延伸 | 事故密度熱點圖、互動式地圖(輸出 HTML) | `事故點分布圖.py`、`互動地圖.py` |

## 專案結構

```
.
├── run_all.py                 # 一鍵產生所有圖表
├── common.py                  # 共用邏輯:資料讀取、篩選第1當事者與四縣市、肇因合併、車輛數加權
├── 當前資料下載更新.py          # 比對官方更新時間,有更新才下載
├── 資料塞入資料庫.py            # 將下載的 CSV 匯入 SQLite (data.db)
└── 各章節分析腳本 (*.py)        # 每支腳本產生對應章節的圖表
```

`common.py` 把每個圖表都需要的篩選邏輯集中管理,新增圖表時直接 import,不必重複貼上同一段程式。

## 資料處理重點

- **只計算第 1 當事者**:同一起事故可能有多位當事者,為避免重複計算,以第 1 當事者代表該事故。
- **範圍限定北北基桃四縣市**。
- **肇因合併**:把多種「未依規定讓車」子類別合併為一個大類,並排除「尚未發現肇因」等無效紀錄。
- **車輛數加權**:各縣市規模差異大,事故件數換算為「每十萬輛機動車事故件數」(車輛登記數來自交通部公路局統計)再比較。

## 使用方式

### 1. 安裝套件

```bash
pip install pandas matplotlib numpy requests geopandas folium
```

圖表使用 `Microsoft JhengHei`(微軟正黑體)顯示中文,Windows 內建,其他系統需自行調整 `common.py` 內的字型設定。

### 2. 準備資料

資料庫檔 `data.db` 與原始下載檔因體積大,**未放進此倉庫**。請自行下載:

```bash
python 當前資料下載更新.py   # 從 data.gov.tw 下載官方資料到 downloads/
python 資料塞入資料庫.py     # 匯入並產生 data.db
```

### 3. 產生圖表

```bash
python run_all.py                  # 以現有 data.db 重跑所有圖表
python run_all.py --refresh        # 先檢查官方資料有無更新,再下載、匯入、重跑
python run_all.py --with-optional  # 連同熱點圖與互動地圖一起執行
```

所有圖表輸出到 `outputs/` 資料夾。

## 使用技術

Python、pandas、SQLite、matplotlib、geopandas、folium
